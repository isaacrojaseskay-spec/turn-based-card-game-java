# Turn-Based Card Game Java

Turn-based card game developed in Java using data structures and game logic.

## Features
- Multiple player support
- Turn-based round system
- Dynamic score calculation
- Card comparison system
- Winner detection
- Input validations

## Data Structures Used
- Linked Lists
- Circular Lists
- Stacks
- Nodes

## Game Logic
- Players are assigned cards during rounds
- Each card is compared against a reference card
- Higher card = 2 points
- Equal card = 1 point
- Lower card = 0 points
- The player with the highest score wins

## Technologies Used
- Java
- NetBeans

## Concepts Applied
- Data structures
- Object-oriented programming
- Game flow control
- Validations and logic handling
